CHARACTER TEMPLATES

Start from a drawn character and make it yours. Loading replaces every frame, the size and the palette; one Ctrl+Z puts it all back.

IMPORT PNG SHEET

Pick a PNG sprite sheet and its frame size. Frames are sliced left-to-right, top-to-bottom on a uniform grid. Pixels below 50% alpha become transparent; partial alpha is dropped.
