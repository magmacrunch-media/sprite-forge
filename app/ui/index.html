the origin

The point the game positions a sprite by — the feet, for someone walking. It is kept in the .forge file and handed to the loader at run time. It is never written into a PNG, so every engine reading a sheet has to be told it separately.

the two files

A .forge file is the whole project: every sprite, the one shared palette, the origins and the frame rates. It is JSON, and deliberately readable in a diff. A PNG sheet is only pixels — a uniform grid of frame-width by frame-height cells, counted left to right, then top to bottom.

one palette

Every sprite in a project draws from the same swatches, so a character's eight facings cannot drift onto eight slightly different browns. REPLACE and a theme both follow that palette across every sprite. The .forge key names at most 89 colours; go over and saving offers to merge the least-used into their nearest neighbours.
